Sobre mí

Soy de España y estoy estudiando desarrollo web. Me interesa especialmente la parte visual de las páginas, como los colores, la organización del contenido y que todo se adapte bien al móvil.

En este proyecto he usado HTML para crear la estructura de la página y CSS para darle estilos, añadir diseño responsive y organizar los elementos con Flexbox y Grid.
